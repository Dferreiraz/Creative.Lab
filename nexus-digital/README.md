## 📄 Descrição do entregável

- Website institucional responsivo para a **NexusDigital**, apresentando serviços de desenvolvimento web, UI/UX, marketing digital, SEO, inteligência artificial, automação e soluções em cloud.
- Projeto desenvolvido em **15/08/2026** durante o curso de **IA Generativa com Google Antigravity**.

---

## 💻 Sobre o projeto

O **NexusDigital** é um projeto desenvolvido como exercício prático durante um curso de **IA Generativa com Google Antigravity**, explorando o uso de inteligência artificial como ferramenta de apoio à criação de interfaces e experiências web.

A proposta foi construir uma landing page institucional moderna, com estética tecnológica e foco em apresentar uma empresa fictícia de soluções digitais.

O projeto reúne diferentes seções para apresentar os serviços da empresa, seus diferenciais, processo de trabalho, planos, depoimentos, informações de contato e chamadas para ação.

---

## 🎨 Layout

O projeto utiliza uma identidade visual moderna e tecnológica, baseada em um **tema escuro**, gradientes em tons de índigo e roxo, elementos translúcidos e efeitos de brilho.

A interface foi estruturada para transmitir uma proposta de inovação, tecnologia e alta performance.

## 🚀 Como executar o projeto

### Pré-requisitos

Você só precisa de um navegador moderno e, opcionalmente, de um editor de código como o VS Code.

### Executando localmente

1. Clone o repositório:

```bash
git clone https://github.com/Dferreiraz/NexusDigital.git
```

2. Acesse a pasta do projeto:

```bash
cd NexusDigital
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no VS Code para executar o projeto durante o desenvolvimento.
