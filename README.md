## 💻 Sobre o projeto

O **Creative.Lab** é um laboratório de projetos criativos e experimentais dedicado à exploração de ideias que conectam desenvolvimento de software, design de interfaces, visualização de dados e desenvolvimento de jogos desenvolvidos durante o curso Inteligência Artificial Generativa com Google Antigravity no SENAI Suiço-brasileira.

O repositório reúne aplicações com diferentes objetivos e propostas, desde dashboards interativos e sites institucionais até jogos 2D desenvolvidos com tecnologias web.

A iniciativa também explora o uso da **Inteligência Artificial Generativa** como ferramenta de apoio ao desenvolvimento, permitindo experimentar soluções, acelerar a prototipagem, investigar novas abordagens e transformar ideias em aplicações funcionais.

Cada projeto possui características e desafios próprios, incentivando a experimentação técnica, a resolução de problemas e a evolução contínua das habilidades de desenvolvimento.

A proposta é utilizar a criatividade como ponto de partida para construir experiências digitais que unam funcionalidade, tecnologia e identidade visual.

### 🎯 Objetivos do projeto

- Desenvolver projetos web criativos e funcionais.
- Explorar diferentes possibilidades de desenvolvimento com HTML5, CSS3 e JavaScript.
- Criar jogos 2D com mecânicas interativas e lógica de colisão.
- Experimentar a Canvas API para renderização de elementos gráficos.
- Desenvolver dashboards para visualização e análise de dados.
- Praticar princípios de UI/UX e design responsivo.
- Explorar animações, efeitos visuais e interações dinâmicas.
- Utilizar Inteligência Artificial Generativa como apoio à prototipagem e ao desenvolvimento.
- Experimentar diferentes arquiteturas e abordagens para aplicações web.
- Construir um portfólio de projetos que demonstre criatividade, capacidade técnica e evolução profissional.

## 🧠 Conceitos praticados

Os projetos do Creative.Lab permitem trabalhar diferentes conceitos relacionados ao desenvolvimento web, à criação de jogos e à experimentação tecnológica.

### 🎨 Design de interfaces e UI/UX

- Construção de layouts modernos e visualmente consistentes.
- Hierarquia visual e organização de conteúdo.
- Tipografia, cores, espaçamentos e identidade visual.
- CSS Grid e Flexbox.
- Design responsivo e adaptação a diferentes dispositivos.
- Animações, transições e efeitos visuais.
- Criação de componentes e elementos interativos.

### 💻 Desenvolvimento web

- HTML5 semântico.
- Organização e estruturação de páginas.
- CSS3 e modularização de estilos.
- JavaScript ES6+.
- Manipulação do DOM e gerenciamento de eventos.
- Lógica de programação e estruturas de dados.
- Atualização dinâmica de conteúdo.
- Consumo e apresentação de dados em interfaces.
- Organização de arquivos e componentes por projeto.

### 🎮 Desenvolvimento de jogos 2D

- Renderização gráfica com HTML5 Canvas.
- Movimentação e controle de personagens.
- Sistemas de colisão e detecção de objetos.
- Coleta de itens e interação com o ambiente.
- Lógica de inimigos e comportamentos básicos de IA.
- Sistemas de pontuação, objetivos e condições de vitória ou derrota.
- Atualização de estados e ciclos de jogo.
- Animação de personagens e elementos gráficos.

### 📊 Visualização de dados

- Organização e apresentação de informações.
- Criação de dashboards interativos.
- Construção de métricas e indicadores.
- Rankings e comparações de dados.
- Gráficos e representação visual de informações.
- Exploração de bibliotecas de visualização, como Chart.js, quando aplicável.

### 🤖 Inteligência Artificial Generativa

- Utilização de IA como apoio à prototipagem.
- Exploração de ideias e soluções para desafios de desenvolvimento.
- Geração e refinamento de componentes e interfaces.
- Análise, revisão e otimização de código com auxílio de IA.
- Experimentação de diferentes abordagens de implementação.
- Avaliação e validação das soluções geradas antes de sua integração aos projetos.

> A Inteligência Artificial é utilizada como ferramenta de apoio. A implementação, os testes e a validação das soluções continuam sendo partes importantes do processo de desenvolvimento.

## 🛠️ Tecnologias

As tecnologias podem variar de acordo com os objetivos e as necessidades de cada projeto.

### Front-End

- **HTML5** — Estruturação semântica de páginas e suporte à Canvas API.
- **CSS3** — Estilização, layouts, animações e design responsivo.
- **JavaScript ES6+** — Lógica de programação, interatividade e manipulação de dados.
- **HTML5 Canvas** — Renderização de gráficos e implementação de mecânicas de jogos 2D.
- **Chart.js** — Biblioteca para criação de gráficos e visualizações de dados, quando utilizada pelo projeto.

### Inteligência Artificial

- **IA Generativa** — Apoio à ideação, prototipagem, análise e desenvolvimento de soluções.
- **Google Antigravity** — Ambiente de desenvolvimento com recursos de IA, utilizado como ferramenta de apoio quando aplicável.

### Ferramentas de desenvolvimento

- **Visual Studio Code** — Ambiente de desenvolvimento.
- **Live Server** — Execução local das páginas durante o desenvolvimento.
- **Git** — Controle de versão.
- **GitHub** — Hospedagem do código e acompanhamento da evolução dos projetos.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Dferreiraz/Creative.Lab.git
```

### 2. Entre na pasta do projeto

```bash
cd Creative.Lab
```

### 3. Abra o projeto no Visual Studio Code

```bash
code .
```

### 4. Execute no navegador

Abra o arquivo `index.html` localizado na raiz do repositório para acessar o menu principal do Creative.Lab.

Você também pode utilizar a extensão **Live Server** no Visual Studio Code para executar a página localmente.

Para acessar um projeto específico, navegue até a pasta correspondente e abra seu arquivo `index.html`, quando disponível.

**Observações:**

- A estrutura e o modo de execução podem variar conforme cada projeto.
- Projetos que consomem APIs externas podem exigir conexão com a internet.
- A utilização do Live Server é recomendada durante o desenvolvimento e os testes.
- Caso algum projeto possua dependências ou instruções próprias, consulte o README específico, se disponível.
